## Project Overview

ChatbotAI is a frontend application built using **Angular**.
It provides a chatbot interface and is deployed online for live access.

You can access the live application here:

👉 https://chatbotai-ygqn.onrender.com/

---

## Built With

* Angular CLI 21.2.2
* TypeScript
* HTML / CSS
* Node.js

---

## Development Server

To start the local development server, run:

```bash
ng serve
```

After the server starts, open your browser and navigate to:

```
http://localhost:4200/
```

The application will automatically reload whenever you modify any source files.

---

## Code Scaffolding

Angular CLI provides powerful scaffolding tools.

To generate a new component:

```bash
ng generate component component-name
```

To see all available schematics (components, directives, pipes, etc.):

```bash
ng generate --help
```

---

## Building the Project

To build the project run:

```bash
ng build
```

The compiled build files will be stored in the:

```
dist/
```

directory.

The production build automatically optimizes the application for performance.

---

## Running Unit Tests

To run unit tests using **Vitest**, execute:

```bash
ng test
```

---

## Running End-to-End Tests

To run end-to-end tests:

```bash
ng e2e
```

Angular CLI does not include an E2E framework by default, so you can install one like **Cypress** or **Playwright**.
